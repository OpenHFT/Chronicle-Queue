[source,shell]

  -Dsurefire.rerunFailingTestsCount=0 clean verify -l /tmp/pr1706-verify.log
----

`src/test/java/net/openhft/chronicle/queue/bench/LastSequenceNumberJLBHBenchmark.java`

[source,shell]

  -DincludeScope=test -Dmdep.outputFile=target/bench-classpath.txt \
  -l /tmp/pr1706-benchmark-compile.log

vectors, and this classpath:

Use the following properties for each revision, once with `appenders=1` and once
with `appenders=2`:

[source,text]
----
-XX:ActiveProcessorCount=4
-Drevision=<exact production revision>
-Dpath=<existing benchmark parent directory>
-Dappenders=1
-Drecords=10000
-Diterations=500
-Dthroughput=500
-Druns=3
-DwarmUp=100
net.openhft.chronicle.queue.bench.LastSequenceNumberJLBHBenchmark

The benchmark creates and removes its own child directory. The supplied parent
is never recursively deleted. The recorded validation also placed a sentinel
queue file in that parent and checked its contents after each run. Run without
other builds/benchmarks on the machine for a more controlled comparison.

Each invocation writes another record. The raw output reports population and
distance from the sparse index at each run boundary. Compare the same boundaries;
do not describe these as fixed-size queues or infer a concurrent stress result.

== Repeat targeted mutations

In a separate worktree at the implementation revision, apply one entry from
`mutation-definitions.json` at a time. Require exactly one occurrence of its
`before` text, replace it with `after`, and run:

[source,shell]
----
mvn -B -ntp -nsu -DargLine=-XX:ActiveProcessorCount=4 \
  -Dsurefire.rerunFailingTestsCount=0 -Dtest=<entry.test> test \
  -l /tmp/pr1706-mutation.log
----

Remove the corresponding old Surefire XML report before each execution. A killed
mutation must compile, execute its selected test and produce a test failure;
compile errors, missing reports and timeouts are invalid runs. Restore the exact
source before proceeding to the next mutation. After the last restoration,
run the clean focused verification above to discard mutated classes.
