== Timing and allocation diagnostic

`QueueLookupAuditBenchmark.java` is a standalone diagnostic. It creates and
removes only its own temporary queue directory. It does not accept an existing
queue path. Use the same class bytecode for all three production revisions.

In each production worktree, obtain the compiled classes and dependencies:

[source,shell]
----
mvn -B -ntp -nsu -DskipTests test-compile dependency:build-classpath \
  -DincludeScope=test -Dmdep.outputFile=target/audit-classpath.txt \
  -l /tmp/queue-audit-compile.log
----

Compile the diagnostic with Java 21 and the project's test dependency classpath.
Put the resulting diagnostic classes, the selected worktree's `target/classes`
and those dependencies on the runtime classpath. The exact original argument
vectors are recorded in `api-*.command.json`; substitute local classpath paths
and use the same exports/opens and JVM options. For each revision, launch a
separate JVM for each of:

[source,text]
----
QueueLookupAuditBenchmark FAST_DAILY
QueueLookupAuditBenchmark HUGE_DAILY
QueueLookupAuditBenchmark HUGE_DAILY_XSPARSE
----

Pass the exact revision with `-Drevision=...`. The common options are `-Xbatch`,
`-Xms256m`, `-Xmx256m` and `-XX:ActiveProcessorCount=4`. The output records
runtime details, actual population and all four measured batches. Operation
warmup is 20,000 calls. Summaries use the median of the batch means from rounds
2-4; they are not latency percentiles. The allocation counter covers only the
calling thread's Java heap allocations.

The files are grown by document/direct-byte write operations before read-only
operations are measured. Both population and sparse-index distance therefore
matter when comparing rows. All revisions receive the same call counts and
contents. Timing is supporting evidence from one development host; deterministic
work bounds are the acceptance gate. The original host information remains in
`../pr-1706-evidence/benchmark-host.txt`, and filesystem/JVM details are in the
earlier raw output. This run also uses that Linux/ext4 host and Java 21.0.12.
