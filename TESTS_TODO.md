## Research Inputs (why these tests matter)
- **Chronicle-Logger configs** — bindings expose `blockSize`, `bufferCapacity`, `rollCycle`, and `wireType` overrides that must remain in sync with `SingleChronicleQueueBuilder`. See `NEW_TESTS.md` for references to the logger README and compatibility gotchas.
- **Async buffers & ring bridges** — Enterprise mode wraps write/read buffers in a ring to soak OS jitter. Queue core should encode ordering/backpressure expectations before Enterprise falls over.
- **File growth & partial frames** — Replication/preloader flows skip incomplete SPB frames and zero-length payloads; CLI users hit the same code paths during restarts.
- **Named tailers & QueueOffsetSpec** — Failover relies on persisting exact indexes/DST-aware roll times; negative cases must fail fast.
- **CLI/TextWire patterns** — Demos/CLI mains demonstrate `Jvm.pause`, `MessageHistory`, and MethodReader loops that consumers copy verbatim.
- **Pretouch & page-size constraints** — Long-lived pretouchers must close cleanly and refuse to run on unsupported filesystems/page sizes.
- **Service-driven replication, roll-cycle guardrails, and “do-not-do-this” scenarios** — Research items captured in `NEW_TESTS.md` (NFS avoidance, TCP byte-stream assumptions, ring-buffer jitter claims) inform acceptance tests for the batches below.
